# Отчёт о подготовке bootstrap

Дата: 2026-11-01. Рабочая ветка: `experiment/agency-bootstrap`.

- Сохранены восемь оригинальных ролей, оригинал стратегии NEXUS и MIT-лицензия по закреплённому commit; повторное получение каждого файла совпало с сохранёнными байтами. Источники и хэши — в `AGENT_REGISTRY.md`.
- Проведён ограниченный ручной и шаблонный аудит, создано восемь проектных определений, business brief и протокол эксперимента. Найденные риски и их ограничения — в `SECURITY.md`.
- `claude --version`: 2.1.119. `claude agents --setting-sources project` перечислил восемь проектных ролей; проверены структура, имена, обязательные поля и read-only список инструментов. Это не проверка их вызова и фактического применения ограничений.
- Реальные вызовы Claude-субагентов, полный эксперимент, исследование, документы архитектуры, независимая проверка Codex результатов Claude и использование модели не выполнялись. Поэтому критерий работы команды после одного задания ещё не проверен end-to-end; расход и usage для такого запуска неизвестны.
- На момент подготовки удалённый репозиторий не имел веток/коммитов, `defaultBranchRef` пуст. GitHub сообщает права ADMIN, но публикация не разрешена. Draft PR нельзя создать без опубликованной базовой ветки и отдельной опубликованной ветки изменений. Автоматическое объединение с main не выполнялось.
- Проектных настроек MCP, hooks, обхода permissions, установок и секретов не добавлено. Ограничения инструкций не являются песочницей для координатора.
